Bot de tickets

Configurá todo lo que hace el bot de tickets de Discord: el panel que ven los clientes, el botón, dónde se crean los tickets y qué mensaje reciben adentro. El bot lee esta configuración solo — no hace falta tocar código.

Importante: acá NO se carga el token del bot (la clave secreta de Discord). Ese token va únicamente en el servidor donde corre el bot, nunca en esta página, porque cualquiera podría verlo abriendo el navegador. Todo lo de acá abajo es seguro de guardar: son solo IDs, textos y colores.

Cada usuario aprobado puede cargar, desde su propio panel (mibot.html), el ID de su servidor de Discord para usar el bot ahí. El bot NO funciona en ningún servidor hasta que vos lo apruebes acá.

Cargando servidores…

Esta es la configuración del bot para tu propio servidor de Discord (el de la tienda). No necesita aprobación porque la cargás vos mismo.

Ubicación
Los ID se consiguen activando el "Modo desarrollador" en Discord (Ajustes → Avanzado) y haciendo clic derecho sobre el servidor, canal, categoría o rol → "Copiar ID".
Clic derecho sobre el ícono del servidor en Discord → "Copiar ID del servidor". El bot usa este ID para saber que esta configuración es la de ESTE servidor.
Estos roles ven automáticamente todos los tickets que se crean. Dejalo vacío si no querés dar acceso a ningún rol.
Cuántos tickets puede tener abiertos a la vez la misma persona en este servidor. Dejalo en 0 para no poner límite.
Si nadie escribe en el ticket durante estos minutos, el bot avisa y lo cierra solo unos minutos después. Dejalo en 0 para desactivarlo.
Mensaje del panel (donde tocan para abrir un ticket)
Esto es lo primero que ve el cliente en el canal público.
Elegís la foto desde tu compu, se sube sola. Si no elegís una nueva se mantiene la que ya tenías.
Con "varios tipos" podés armar, por ejemplo, "Soporte", "Compras" y "Reportar un bug", cada uno con su propia categoría de Discord. Se muestran como botones o como un menú desplegable.
Para usar un emoji propio del servidor: escribí \:nombre_del_emoji: en cualquier canal de Discord (con la barra invertida) y mandalo. Discord te muestra el código completo, tipo <:nombre:1234567890>. Copiá y pegá ESE código acá.

Variables disponibles

Usalas en el nombre del canal y en los mensajes de bienvenida — el bot las reemplaza automáticamente al crear cada ticket.

{usuario}Menciona (@) a quien abrió el ticket.
{USER_ID}El ID de Discord de esa persona.
{GUILD_NAME}El nombre del servidor de Discord.
{TICKET_NUMBER}Número correlativo del ticket (1, 2, 3…), nunca se repite.
{CANAL}Menciona el canal del ticket recién creado (solo tiene efecto en el mensaje de bienvenida).
{FECHA}La fecha en que se abrió el ticket.
{HORA}La hora en que se abrió el ticket.
